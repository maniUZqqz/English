# English Lady 🎓

پلتفرم کامل موسسه زبان انگلیسی با هوش مصنوعی — تماماً روی **Django**، با رابط **فارسی RTL + دارک‌مود**.

> فایل‌های قدیمی (پروژه Express، اپ خالی PDF_reader و…) در پوشه [`old/`](old/) آرشیو شده‌اند — استفاده نمی‌شوند و هر وقت خواستید قابل حذف‌اند.

## امکانات

### 🏫 موسسه (کلاس آنلاین)
| بخش | توضیح |
|---|---|
| نقش معلم/زبان‌آموز | از پنل ادمین ← User profiles تنظیم می‌شود |
| کلاس با کد عضویت | معلم می‌سازد، زبان‌آموز با کد ۶ حرفی عضو می‌شود |
| برنامه هفتگی | روز/ساعت جلسات + «جلسه بعدی» روی داشبورد |
| جلسات و حضورغیاب | حاضر / غایب / تأخیر / موجه |
| تکلیف | تحویل متنی + پیوست فایل، نمره ۰-۱۰۰ و بازخورد معلم |
| آزمون کلاسی | ساخت دستی یا با AI، تایمر، تصحیح خودکار، نتایج برای معلم |
| کارنامه | حضور + تکالیف + آزمون‌ها + میانگین کل، قابل چاپ |
| گفتگو | پرسش‌وپاسخ زیر هر تکلیف |
| اطلاعیه | اعلان‌های کلاس |

### 📊 داشبورد و حساب

## راه‌اندازی

```bash
cd python/EnglishWoman
pip install -r ../requirements.txt
python manage.py migrate
python manage.py createsuperuser   # اگر ندارید
python manage.py runserver
```

سپس: `http://127.0.0.1:8000`

## تنظیم کلید API از پنل ادمین 🔑

1. ورود به `/admin/`
2. **AI Configuration** ← کلید API، آدرس پایه، مدل و سقف مصرف روزانه را وارد کنید
3. هر فیلد خالی از `.env` خوانده می‌شود؛ با `is_active` می‌توانید AI را موقتاً خاموش کنید

بخش کلاس (تکلیف، آزمون، حضورغیاب، کارنامه) **بدون کلید API هم کامل کار می‌کند.**

## نقش معلم

پنل ادمین ← **User profiles** ← ستون Role را روی Teacher بگذارید. معلم‌ها دکمه «ساخت کلاس» را در `/classes/` می‌بینند.

## پیکربندی (.env)

| متغیر | توضیح |
|---|---|
| `AI_API_KEY` | کلید API (اولویت با مقدار ادمین است) |
| `AI_BASE_URL` | آدرس پایه سازگار با OpenAI (پیش‌فرض MetisAI) |
| `AI_MODEL` | نام مدل (پیش‌فرض `gpt-4o-mini`) |
| `AI_DAILY_LIMIT` | سقف درخواست AI هر کاربر در روز (پیش‌فرض ۱۰۰) |
| `DJANGO_SECRET_KEY` | برای استقرار حتماً عوض کنید |
| `DJANGO_DEBUG` | `False` برای استقرار |
| `EMAIL_BACKEND` و `EMAIL_*` | برای ارسال واقعی ایمیل بازیابی رمز (پیش‌فرض: چاپ در کنسول) |

## ساختار پروژه

```
python/EnglishWoman/
├── EnglishWoman/        # تنظیمات + services.py (لایه AI — ادمین یا .env)
├── app/                 # احراز هویت، تعیین سطح، داشبورد، پروفایل، سهمیه/استریک، AIConfig
├── qqz/                 # درس‌نامه و آزمون‌های شخصی
├── tools/               # ابزارهای AI + دفتر لغات + لایتنر + شنیداری + حافظه چت
├── classroom/           # موسسه: کلاس، جلسه، حضورغیاب، تکلیف، آزمون، کارنامه، گفتگو
├── tem/                 # قالب‌ها — فارسی RTL + دارک‌مود (base.html)
├── static/              # تصاویر و ویدیو
└── media/               # فایل‌های آپلودی (پیوست تکلیف)
```
