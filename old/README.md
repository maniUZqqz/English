# پوشه old — فایل‌های قدیمی و بلااستفاده 🗄️

هیچ‌چیز در این پوشه توسط پروژه استفاده **نمی‌شود**. فقط برای آرشیو نگه داشته شده؛ هر وقت مطمئن شدید می‌توانید کل پوشه را حذف کنید.

| مورد | چی بود |
|---|---|
| `js/` | پروژه قدیمی Node/Express (AI-English-Teacher) — هر ۵ ابزارش به جنگو (`tools/`) منتقل شده |
| `PDF_reader/` | اپ جنگوی نیمه‌کاره و خالی — از INSTALLED_APPS حذف شده؛ ایده‌اش (Reading از PDF) در نقشه راه هست |
| `PDF-templates/` | قالب `input.html` مربوط به همان اپ |
| `Teach-front.html` | قالب بلااستفاده که هیچ ویویی رندرش نمی‌کرد |
| `controller.py` | کد تماماً کامنت‌شده‌ی چت CLI قدیمی |
| `QQz.md` | فایل خالی |
| `python-README.md` | راهنمای قدیمی (سه دستور migrate/runserver) — جایگزینش README اصلی ریشه است |
| `unused-images/` | تصاویر قدیمی `static/images` که هیچ قالبی استفاده‌شان نمی‌کرد |
